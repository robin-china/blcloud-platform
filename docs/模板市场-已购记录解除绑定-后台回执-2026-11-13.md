结论：**契约全部接收，后台已实现完毕，无驳回项。** 客户端无需改动已写好的调用代码。

## A. 接口契约逐条确认

| 项 | 需求单 | 后台实际值 |
|---|---|---|
| 唯一 path | `POST /api/open/v1/market/owned/:templateId/discard` | **一致**，`:templateId` 为 `market_templates.id`（形如 `tpl_mkt_xxx`） |
| 鉴权 | Bearer + `x-nonce` | **一致**，沿用 `requireClientWrite`（与 `/market/redeem` 同一守卫） |
| 请求体 | `{ "machine_code": "硬盘序列号哈希" }` | **一致**，兼容别名 `machine_id` |
| 成功响应 | `{ ok:true, discarded:true, serverTime }` | **一致** |
| 未购响应 | `ok:true, discarded:false` | **一致**，幂等不报错；模板不存在同处理 |
| 缺机器码 | `400 MACHINE_REQUIRED` | **一致** |
| 机器码不符 | `403 MACHINE_MISMATCH` | **一致**，与 `/license/ticket`、`/market/redeem` 同口径 |
| 未登录 / 令牌失效 | `401 UNAUTHORIZED` | **一致** |
| 事务 | 单事务删 `market_purchases` 对应行 | **一致**，且幂等 |

补充两项服务端行为（不改变响应结构）：

- 缺 `x-nonce` → `401 NONCE_REQUIRED`；同一 nonce 重放 → `401 NONCE_REUSED`。
- 同账号超过 30 次/分钟 → `429 RATE_LIMITED`。

## B. 语义逐条确认

1. **仅解除绑定**：删除 `(user_id, template_id)` 那一行，不动模板、不动文件、不动其它账号。
2. **不返还积分**：不写 `points_logs`，余额完全不变；本地已下载的 `.blls` 保留，客户端不要顺手删用户磁盘文件。
3. **丢弃后可重新兑换**：回到「未拥有」状态，再次 `/market/redeem` 会**重新扣分**（`already:false`）。免费模板自然不扣分。
4. **删除保护不变**：后台「有用户兑换过的模板只能下架、不能删除」规则原样保留；**所有**已购用户都丢弃后，该模板即可被后台删除。需求单里「让后台能删」的诉求由此闭环。
5. **已购归账号**（沿用 2026-11-13 拍板口径）：按当前会话 `user_id` 解绑，与机器码无关但机器码必须匹配会话；换机后仍能看到并丢弃自己的资产。

## C. 我方额外加固（请客户端知晓）

**丢弃会作废该账号该模板尚未消费的下载短链。** 需求单写「丢弃后只是不能再从市场重新下载」，但如果丢弃前刚兑换过、5 分钟短链还在手上，光删已购行等于「卡片藏起来了、文件照样能下」。所以后台在同一事务里删掉了 `market_download_links` 中该 `(user_id, template_id)` 未消费的行：

- 旧短链再请求返回 `404 LINK_NOT_FOUND`（不是 `LINK_INVALID`，不要当成签名错误去排查）；
- 客户端按「已失效」处理即可，**不要自动重新兑换**（会自动再扣分）；
- 已消费的短链记录保留，按 1 天留存滚动清理，不随丢弃删除。

另加了跨账号隔离：别人拿自己的有效 Bearer 调这个 path 只会得到 `discarded:false`，动不了你的已购记录。

## D. 完整调用示例

```bash
curl -X POST \
  'https://www.bliot.cn/platform/api/open/v1/market/owned/tpl_mkt_3676207a09e1c4/discard' \
  -H 'Authorization: Bearer <access_token>' \
  -H 'X-Nonce: <每次新值，UUID 即可>' \
  -H 'Content-Type: application/json' \
  -d '{"machine_code":"<硬盘序列号哈希>"}'
```

```json
{ "ok": true, "discarded": true, "serverTime": "2026-11-13T14:00:00.000Z" }
```

确认文案建议沿用需求单原文：「丢弃后将从「我的已购」移除，且不退还积分。确定丢弃？」

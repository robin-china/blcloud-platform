## 3. 关键实现口径（给软件端 / 给运维）

1. **列表与详情不返回 `fileUrl`、不返回任何文件路径**；`fileSha256` / `fileSize` 可公开展示，真正的文件只能经短链取。
2. **游标 = `(sortKey, id)` + 筛选指纹 MAC**。换排序/换筛选/改 `q`/切 `mine` 后必须丢掉旧游标从第一页重拉，否则 `400 CURSOR_INVALID`；服务端 `ORDER BY sortKey, id` 走联合索引，不用 offset。
3. **兑换是单事务**：先确认私有文件存在 → 条件扣分 → 写流水 → 写已购 → 签短链。任一步失败全回滚，不会出现「扣了分没发货」或超扣。
4. **短链**：5 分钟 TTL、一次性 `jti`（`UPDATE ... WHERE used_at=''` 抢占）、签名绑定 `template+user+machine`，过期/重放分别 `410 LINK_EXPIRED` / `410 LINK_USED`。已购重新兑换即可领新链，不扣分。
5. **离线期间禁止放行兑换**：客户端 `credits.json` 只是展示缓存，本地扣分/本地解锁必然双花。
6. **已购归账号**：`machine_code` 仍必填且与会话一致（沿用 `MACHINE_MISMATCH` 口径），但不作为资产归属键。
7. **写接口 Bearer + x-nonce 只在新接口强制**，`/auth/refresh` 等老接口保持原契约，1.0.54 客户端不受影响。
8. **下载量热度会变**：重复下载也累加，按 `downloads_desc` 翻页时可能有轻微重复/抖动，客户端按 `id` 去重；要绝对稳定需改成「快照 top N」，本版按清单的游标方案实现。

## 4. 上线步骤与检查

1. 部署（**完整命令**）：`cd /opt/blcloud && git pull && pm2 restart blcloud-admin`
2. 首次启动自动建表 + 种枚举字典，无需手工执行 SQL；私有目录 `data/market/` 会自动创建。
3. 后台「模板字典」按实际运营词表改一遍 → 「模板市场」逐个上架模板、上传 `.blls` 与缩略图。
4. **Nginx 检查**：确认没有 `/platform/market/` 之类的静态 alias；`data/market/` 不在 `public/` 内，Fastify 也没有挂载它。
5. **备份检查**：新建一次带上传文件的备份，确认包内出现 `market/*.blls` 与 `manifest.json` 的 `market` 字段。
6. 客户端联调先跑 `/market/meta` → `/market/list` → `/market/detail`，再走登录 → `/user/credits` → `/user/signin` → `/market/redeem` → 下载短链。

无新增环境变量；`MARKET_DIR` 可选（默认 `data/market`）。短链签名复用 `data/.appsecret` 主密钥派生，
**主密钥仍须与 `app.db` 同批备份**，否则短链全部失效。

### 6.3 支持 API 上架（评估后的方案）

**评估结论：不能把后台 CRUD 开出来给外部用。** 管理员 JWT 12h 过期且等于全后台权限、
无法单独吊销；现接口没有幂等键（超时重试必重复建模板）、不校验字典（批量灌脏枚举）、
没有来源/审核概念（拿到凭据就能直接对外上架）。

落地方案（详见《模板市场-API上架接入.md》）：

- **独立前缀 `/api/market/v1` + 独立密钥** `X-Market-Key`：明文只在创建时返回一次，
  `sha256` 入库，可单独启停/删除，限流 120 次/分钟，每次调用写 `market_api_logs`（留存 30 天）；
- **幂等**：`externalId` 为幂等键，唯一索引 `(source, api_key_id, external_id) WHERE source='api'`。
  内容没变时 no-op，连 `version` 都不动；超时直接同键重试即可；
- **默认待审**：`auto_publish=0` 建为 `off`，后台审核后点「上架」；只有可信官方脚本才开 `auto_publish=1`。
  **运营人工下架后，脚本重跑不会偷偷推上线**（更新保留现有 status）；
- **字典强校验**：行业 / 纸型必须在字典内，dpi 必须在允许集内，宽高必须 >0；
  《只作用于 API 通道》，后台人工通道保持宽松（运营改字典后老模板仍能保存）；
- **文件双通道**：小文件 `fileBase64` 一步式（≤10MB 建议），大文件 multipart 两步式（≤64MB）；
  都可声明 sha256，服务端比对、不一致拒收且不覆盖旧文件；文件名必须 `.blls`；
- **越权隔离**：API 只能改自己密钥建的模板，跨密钥 / 改后台人工模板 `403 TEMPLATE_FORBIDDEN`；
  **删除与下架不开放给 API**，防脚本误伤已购用户；响应永不返回 `file_path` / `fileUrl`；
- **后台管理页**：新建/停用密钥、切换自动上架、最近调用日志、curl 速查。

新增表 `market_api_keys` / `market_api_logs`，`market_templates` 增
`source / external_id / api_key_id` 三列（`ensureColumn` 兼容旧库），
后台列表新增「来源」列与「API 投稿待审」计数。
